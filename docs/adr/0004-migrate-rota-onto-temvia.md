# 使用 npm 发布的 Temvia 作为 Rota 新底座

为降低维护成本，使用 npm 发布的 Temvia 生成底座，将 Rota 全部现有业务功能迁入。通用能力以模板为准，业务接入模板，不并行保留 Rota 原有通用实现；不采用本地模板 checkout 作为生成来源。

允许页面样式、导航和 API 路径按模板调整，但不得裁剪业务能力、业务规则或权限效果。相比将模板零散移植进旧结构，此方案选择统一到底座约定，代价是需要迁移适配与完整的功能验收。

具体 npm 版本在生成前核实并记录；本决定不代表已批准实施。旧数据迁移、连续可用性和上线时间约束暂不讨论，不视为允许删除旧数据。
